## Dyadic arithmetic

`src/openai_ns_reconstruction/original_unbounded_dyadic_product_v1.py` multiplies two finite raw binary intervals by comparing their four exact endpoint products. It keeps each exponent as an integer and never allocates an integer with a number of bits proportional to the exponent's magnitude. Comparisons use the top-bit position and bounded mantissa shifts. The default input mantissa cap is 4096 bits, caller-selectable up to 65536 bits; exponent integers are limited to 256 bits for resource safety. NaN/Inf encodings, malformed tuples and reversed intervals are rejected. The output is a conditional interval product, not a source value or a proof of input enclosures. This module does not add intervals, exponentiate or integrate them, so it is not yet a complete evaluator for the symbolic m15 sum.
