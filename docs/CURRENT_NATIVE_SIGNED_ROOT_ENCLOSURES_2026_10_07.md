## API and output semantics

```python
from lei_ren_part1_paper_compliant_current_checked_source_runtime import native_bridge_owner
from lei_ren_part1_paper_compliant_current_native_generic_source_packets import NativeGenericSourcePackets
from lei_ren_part1_paper_compliant_current_native_signed_input_enclosures import NativeSignedInputEnclosures

bridge, _ = native_bridge_owner()
roots = NativeSignedInputEnclosures(NativeGenericSourcePackets(bridge))
query = roots.query('reshape', Z=(-1, 1), coordinate='.537')
actual_a_cover = query['roots']['a']['y0_Z0']
record = actual_a_cover.record()
```

`query` returns the source packet, original signed jet definition, live leaf covers, numerical signed root enclosures and a serializable record. Each `ScaledEnclosure` is an interval coefficient times a positive logarithmically stored factor. `finite_interval()` accepts only modest exponentials; it rejects huge source materialization. Neither midpoint nor upper endpoint is selected as a field value. A logarithmic rescaling endpoint is an arithmetic coordinate, with the entire signed source interval retained.

For switch_power, reshape and the three restoration charts, the original raw-row formula is replayed with the frozen actual positive amplitude and its square retained on the fourth source basis. Pstar^-2 is retained on the second basis. Only named commutative multiplication/P0-addition sites change orientation to allow mixed Taylor/factor dispatch; the defining source formulas and accepted arbitrary-unit normalization remain unchanged. This avoids dividing two already-capped tiny amplitudes in these five charts. Separate P0 is preserved.

For patch/pre/O3, plain rows remain original prebounded coefficient covers. Their hidden factors are not invented. The native adapter's older generic `source_factor_resolution_performed=False` flag should not be read as a promise that every upstream plain adapter deferred its exponentials. This stage explicitly distinguishes those covers from the five newly deferred amplitude adapters.

The fifth arithmetic basis is the original conservative numeric logR enclosure supplied by the unchanged `seed.radius` method. The exact radius tree is retained as metadata, including microscopic hb offsets. **The tree correlations are not evaluated by this backend.** Its `formal_radius_correlations_used_in_arithmetic` flag is false. A shared fast phase must use the exact radius-offset source, rather than this numeric cover, before integration.

Every original positive E/C/a denominator theorem is decoded in the native packet context. If a coefficient interval crosses zero, the function-level positive lower log and enclosing upper log give a conservative denominator interval. No coefficient is individually declared positive because the underlying function is positive. Source-log powers cancel before evaluation where correlated factors are actually present; independent-wide-log rescaling is separately recorded and can widen covers.

All six ordinary O3 excess derivatives use the unrounded source: Delta=2mu*sigma(t) and D_y^j Delta=2mu*j!*sigma_jets[j], with Z derivatives zero; pure power has Delta=2mu and all higher derivatives zero. Subtracting rounded 2+mu is forbidden.
