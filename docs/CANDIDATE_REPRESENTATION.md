# CR002 — executable compact candidate design

Implementation: `src/openai_ns_reconstruction/constrained_candidate.py`.
Initial artifact: `artifacts/constrained/initial_candidate.json`.
This is a candidate, not a PDE-validated solution.

Let tau=1-t, A=0.505, D=0.495, lr=w_r sqrt(tau), lz=w_z tau^D,
R=r/lr, Z=z/lz. Use the smooth bump B from `constrained_force.py` and
b=B(R²/4)B(Z²/4), q=1+alpha R²/4+beta Z²/4.
Choose streamfunction psi=a r² tau^(-A) Z b q and swirl
u_theta=a c tau^(-A) R b. Define u_r=-psi_z/r and u_z=psi_r/r.
The implementation evaluates the cancelled Cartesian expressions directly,
including at r=0. This follows the axis-regular streamfunction pattern of
`background.py`, `profiles.py` and `local_field.py`; it does not instantiate
their existential paper profile or require the old theorem adapters.

The root selected an odd axial profile (factor Z) so outflow reverses below
the central plane, and uses the already implemented bump primitive. The
Luna/max design review supplied the curl-plus-swirl construction, compact
scaled support and normalization approach. Its alternative polynomial with
nonzero axial center value was not adopted. Exponents match the finite-window
targets already recorded in CR001; this is an autonomous family.

## Structural properties and pending checks

The poloidal field is curl of A=(-y H,x H,0), H=a tau^(-A)Zbq.
Its divergence vanishes by commutation of mixed derivatives. The swirl is
(-y S,x S,0), with S depending only on r²,z,t, and also has zero divergence.
All expressions are smooth in r² on the axis. Flat bump edges give a smooth
zero extension. Maximum support radii 2 w_r sqrt(0.75) and
2 w_z 0.75^D are both below 2. Thus fixed outer support requirements hold.
These mathematical derivations still need the CR010 executable symbolic checks.

For the default initialization, core inflow, positive swirl and positive
axial flow above the center are checked at the configured probe. Width and
shape optimization must retain the same sign checks. Reference energy is
strictly positive for this nonzero smooth field and is normalized by
cylindrical Gauss quadrature (2 pi r dr dz); later quadrature validation must
remain independent of this normalization calculation.

At fixed scaled points, radial speed scales as tau^(-1/2) and swirl/axial
speed as tau^(-A). This prescribed behavior is not evidence of dynamical
growth generated by the NS equation. The candidate has not passed the
momentum residual, force compatibility, independent held-out validation or
optimization requirements. CR003 derivative interfaces remain to be added.

## Version 2 swirl extension

`configs/constraints_v2.json` preserves v1 thresholds and adds swirl coefficients s_r,s_z in [-0.8,0.8], multiplying swirl by (1+s_r R²/4+s_z Z²/4). The axisymmetric divergence identity and compact support remain unchanged. Old v1 artifacts load with both coefficients zero. The v2 artifact family identifies the enlarged parameter space; old experiments and results remain preserved. This modification targets the pressure-independent azimuthal residual, not a relaxed acceptance criterion.

## Version 3 time-dependent swirl collar

Adds (t-0.25)[s_rt(R²-0.01)+s_zt(Z²-0.01)]/4 to the swirl shape multiplier, with each coefficient in [-4,4]. Divergence, axis regularity and compact support are unchanged. Global swirl similarity is no longer an identity; the original 5% core-drift constraint is explicitly penalized and must be independently checked. The radial scaling identity remains unchanged. Old v1/v2 artifacts load with new coefficients zero.

## Version 4 poloidal time dependence

Adds (t-0.25)[p_rt(R²-0.01)+p_zt(Z²-0.01)]/4 to q in the streamfunction. Bounds are [-4,4]. Velocity includes the spatial derivatives of this correction; the legacy numerical curl independently checks the implementation. Divergence, compact support and axis regularity remain structural. The fixed-profile radial scaling identity in CR010 no longer describes the full v4 velocity; use measured core drift instead. No symbolic proof of exact v4 self-similarity is claimed.
