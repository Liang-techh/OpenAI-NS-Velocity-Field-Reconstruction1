## Lazy original q

The implementation uses the original formula:

q=0 when Delta>=eta; otherwise q=sigma(1-Delta/eta)*sqrt((2eta-Delta)/(2a)).

The eta log is the same checked whole-family Section11 scale. Flat boxes return exact zero before division/square root. Active boxes retain the defining source's positive gamma; mixed boxes enclose the active subset with gamma>=eta and take its hull with the exact flat zero. For Delta<=0, sigma is exactly1. Other active arguments use the original monotone sigma interval routine; unresolved arguments keep the conservative sigma range[0,1]. No extra radial multiplier is added.

At O2 buffer, the original log derivative is exactly-1/2 and b=0, so Delta=0. Thus q=sqrt(eta/a)=sqrt(eta/2)>0, however tiny eta is. This positive log-factored value is now retained. It must not be confused with the nearby O3 flat branch.
