# Direct finite-endpoint shape constraints

`wave_endpoint_shape_cache.py` now evaluates the actual affine candidate's
fixed-cylinder endpoint observables directly as nonlinear functions of its
180 time/pressure controls. This allows the solve to constrain endpoint
geometry instead of hoping a prescribed instantaneous slope persists.

The endpoint is k0+1e-6 on the existing 7,776-point cylinder. The mean
endpoint velocity and gradient use the five-point finite-difference stencil;
the initial wave and tangent gradients use analytic Fourier jets. Pressure
columns are exactly zero. The oracle retains enstrophy normalization and
the axial centroid. Its control Jacobian directional check has relative
error 7.99e-8. Predicted original and larger-margin endpoints agree with
their actual saved observations to 1.7e-13 in radius, 7.5e-12 in aspect,
and 2.9e-4 in weighted spin. This validates this sampled evaluator locally,
not continuum geometry or NS dynamics.

`endpoint_shape_tangent.py` combines this oracle with the moment-nullspace
momentum objective and all sampled cone constraints. The requested signed
fractional endpoint changes are [1e-6, 1e-6, 1e-3] for radial contraction,
aspect increase, and weighted-spin magnitude increase, respectively.
