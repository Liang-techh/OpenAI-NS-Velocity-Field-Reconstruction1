# Kokuno Agent 3 — mean-defect contract and next correction interfaces

## Scope of this increment

This increment does **one** executable thing: it turns the actual nonlinear zero-harmonic defect generated by the Agent-2 complete-curl correction into a typed numerical object computed from a real candidate velocity. It does not yet apply a mean correction, radial-stress inverse, or finite correction cycle.

The implementation is `openai_ns_reconstruction.kokuno_mean_defect`. It consumes a public point-batch velocity callable, an actual `KokunoCompleteCurlCorrection`, held-out Cartesian points, and the repository's independent `constrained_validation.residual` operator. It does not accept a hand-entered residual tensor as evidence of success.

## Public source and provenance boundary

Source record: KokunoYumeto, *Forced Navier–Stokes blowup: reconstruction and validation reader (corrected 208-page edition)*, version `2026.09.09-consolidated`, DOI `10.5281/zenodo.22678406`.

The reader's mean-momentum calculation keeps the full wave covariance

`W^{ab} = <w_a w_b>`

inside the mean equations (MC11–MC12). In particular the angular and axial mean rows contain radial/axial divergences of `W^{r theta}`, `W^{z theta}`, `W^{rz}`, and `W^{zz}`, while the radial row contains `W^{rr}`, `W^{zr}`, and `W^{theta theta}`. Therefore the quadratic wave interaction has a genuine zero harmonic; it is not legitimate to discard it merely because the wave itself has zero mean.

The source mean is tied to its cylindrical angular/auxiliary variables. Agent 2 deliberately implements an autonomous Cartesian affine phase rather than that full source geometry. Accordingly this PR uses a uniform shift of the **actual Agent-2 phase** as an engineering projector. This preserves the structural purpose—extract the quadratic zero harmonic—but is not claimed to be the paper-exact angular/auxiliary mean.

## Typed real-defect contract

For base velocity `b` and phase-shifted complete-curl correction `w_phi`, define the pressure/force-free momentum operator

`N(u) = u_t + (u·grad)u - nu Delta u`.

The code evaluates this with the independent fourth-order-space / second-order-time finite-difference validator already used by CR006. It then forms

`D_mean = mean_phi N(b + w_phi) - N(b)`.

For any fixed pressure and force that are unchanged by the phase sweep, those terms cancel in the subtraction. Since `mean_phi w_phi = 0`, all linear terms in `w_phi` cancel as well, leaving the quadratic zero-harmonic defect increment generated by the real composite velocity. This is the numerical analogue of the covariance contribution retained in MC12.

`PhaseMeanDefectSample` keeps the base momentum, all phase-resolved composite momenta/divergences, the phase mean, the mean defect increment, and the nonzero-phase remainder. The report also projects the mean defect onto the cylindrical `e_theta` direction away from the axis.

The contract fails closed if the base is not callable, if the correction is not the Agent-2 complete-curl type, if points are malformed, or if the phase quadrature is too small. The current diagnostic uses 8 phases and independently compares against 16 phases.

## Reserved next operator: compact radial stress inverse

The reader's finite cycle writes the auxiliary-averaged radial stress correction, for weights `e=2` (angular) and `e=1` (axial), as

`M_e = integral r^e F_e(r) dr`,

`sigma_e(r) = -r^{-e} integral_0^r (r')^e [F_e(r') - b_e(r') M_e] dr'`,

with a fixed compact profile `b_e` normalized by `integral r^e b_e dr = 1`. Equal-moment subtraction makes `sigma_e` vanish outside the annulus and gives

`(partial_r + e/r) sigma_e = -F_e + b_e M_e`.

This is the source structure intended for the next Agent-3 increment. It must be applied to a measured defect such as `D_mean`; the implementation must preserve the moment, support, and edge-regularity checks rather than treating an arbitrary stress as a free forcing.

## Reserved finite-cycle contract

The source finite cycle recomputes the radial defect and mean pressure after every substep, then performs supported nonzero-harmonic correction, auxiliary-averaged stress correction, temporal removal of the remaining mean oscillation, and a five-equation moment/defect correction. Its gain audit reports source exponent gains of at least `0.39999` (wave residual), `0.17` (full tangential mean), and `0.89996` (defect) at `kappa_s=1e-5`; those are source-class estimates, **not** numerical gain factors that may be copied into this repository.

Our finite engineering cycle will instead record, at every iteration, independent held-in and held-out residuals before/after, correction norm, divergence, support/moment errors, and a measured contraction ratio. A source exponent gain will never be substituted for an observed residual decrease.
