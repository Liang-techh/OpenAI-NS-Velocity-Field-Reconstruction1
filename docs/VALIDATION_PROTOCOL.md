# 新候选验证协议

开始优化前将以下内容写入可版本控制的配置：domain、time interval、nu、boundary/support、forcing model、非平凡性/归一化、hard constraints、loss 权重、独立验证数据与误差阈值。未确定前状态为 pending，不能发布“通过”。

## 必需指标

| 指标 | 必须记录的内容 |
| --- | --- |
| 非平凡性 | 振幅/能量等归一化、下界及退化解排除方法 |
| 散度 | 解析/符号身份的范围；独立数值最大值与积分范数 |
| NS residual | `u_t+(u·grad)u+grad p-nu Laplacian(u)-f`，单位、规范化尺度及独立实现 |
| forcing | 固定输入或预先限制的参数族；支撑、范数、正则性与能量输入 |
| 边界与支撑 | 指定边界上的误差；紧支撑如被要求必须有结构依据 |
| 频谱与尺度 | 仅测试已明确来源/自主目标；拟合区间、分辨率、误差和偏差 |
| 增长/集中 | 有限窗口观测、敏感性与分辨率影响；不外推成奇异性证明 |
| 稳健性 | 新采样、不同导数方法、至少三个精度级别、适当参数扰动 |

优化采样不能同时充当唯一验证数据。验证器不能直接返回训练 loss 或用同一预先消去的代数残差作答案。可用解析制造解测试验证器，但制造解测试与目标候选结果分开。

有限精度阈值由项目配置和来源要求决定，不预填“任意小”或以显示格式当阈值。若放宽目标，保留旧结果和修改理由，并重新独立验证。

候选状态使用 `not_constructed / candidate / validated_within_scope / failed_validation`，与旧 `paper_exact` 标记分开。当前状态：`not_constructed`。
