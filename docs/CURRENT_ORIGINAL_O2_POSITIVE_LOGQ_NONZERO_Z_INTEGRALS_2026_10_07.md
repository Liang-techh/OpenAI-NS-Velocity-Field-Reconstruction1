## What changed

The source endpoint cell previously had a finite q box touching zero despite the original eta>0. The original flat-cutoff complement is now evaluated in logs:

```text
lambda = 1/y^2 - 1/(1-y)^2
log(1-sigma) = lambda-log(1+exp(lambda))       (y>=1/2)
q^2 = ((3/5)*(1-sigma)+eta)/(4/5+(6/5)*sigma)
q^2(0) = (3/5+eta)/(4/5); q^2(1)=eta/2.
```

The original cutoff equals one because a<=2 and eta>0. The exact derivative d(q^2)/dsigma=-(6/5)*(1+eta)/a^2 is negative, so right/left endpoint log bounds cover each complete continuous source cell. At y=1 the q logarithm is finite; its positive source is never replaced by a flat field. The extraordinary native selected eta and dstar logarithms are retained, without exponentiating them. Tiny finite materializations use directed [0,positive_tail] enclosures, not exact-zero claims.

At the last cell, log|u|=log|p2|+logq-logdstar spans both regular and signed coordinates. Adding small branch thresholds to the enormous logq arithmetic loses them at any feasible precision. The implementation therefore uses a **local log|u| source coordinate**, with the same original u=p2*q/dstar. Conditional log|u| ranges cover |u|<=1/4 and |u|>=1/8 with overlap; the small logarithmic margin keeps directed threshold decisions inside their valid charts. Full q and p2 ranges are conservatively retained on each conditional piece. This may widen the result but cannot discard an original state. Both pieces and every true phase union are evaluated before density hulling.

The local five-slot basis is `(logPstar,logdelta,logL,logabsu,logR)`. All original roots have fourth power zero; q has unit coefficient, fourth power zero and its full logq in the offset; strict-sign u has fourth power one. This basis is deliberately incompatible with standard packets whose fourth slot means zero. Only finite **normalized** density enclosures leave the cell before cross-cell summation. Native physical Pstar/R/S factors are not ordinary floating numbers.

The original constructor AST is changed only at its u assignment, to consume an equivalent bound of that same source function. Original normalized/angle-endpoint code objects are unchanged, with the bounded-log callback widened. Standalone query calls now guard the same native precision as integration, so endpoint absolute values and diagnostic logarithms do not depend on the caller's default mpmath precision.

For the signed coordinate, O2 t0=0 and sign(r)=sign(p2) give the exact identity

```text

```

The implementation keeps the original small-r primitive and uses this equivalent canceled expression for signed B. It retains the original angle difference and signed p2; no B term is dropped. Currently the base primitive is evaluated before signed B is replaced; future generalization should separate A evaluation if another source box makes the preliminary base B arithmetic fail.
