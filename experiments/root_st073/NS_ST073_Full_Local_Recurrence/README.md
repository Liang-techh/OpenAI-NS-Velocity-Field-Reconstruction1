A reproducible **local** Navier–Stokes calculation, not an accepted global candidate.

The new radial recurrence includes all three momentum components, time derivatives,
axial diffusion, radial inertia and pressure. At the registered finite inner domain,
the frozen ST073-V field passes the reported sampled 0.001 momentum checks. The
whole-space compact-support/fixed-force/energy benchmark, exterior matching,
non-axisymmetric waves and scale-recursion capability are **not completed**.

## Evaluate physical velocity, pressure and the complete residual

```python
from full_radial import FullRadialField

field = FullRadialField.load('data/ST073-V.json')
tau = 0.5 / 64                  # remaining time; physical t = 1 - tau
xyz = field.from_similarity([0.004, 0.012], [-0.2, 0.3], tau)
result = field.evaluate(xyz, tau)
print(result['velocity'], result['pressure'], result['residual'])
```

The second argument is **remaining time tau**, not physical time t. Evaluation
outside the registered local coordinate/time window fails rather than silently
extending the field. Coefficients are generated by a deterministic recurrence
from the JSON model; `data/` also contains actual coefficient and field snapshots.
The minimal GitHub evaluator needs `full_radial.py`, `upstream/source_coordinates.py`
and a model JSON plus NumPy/SciPy. The full audit/test dependencies are in this ZIP.

## Registered scope

- Physical viscosity 0.01, local unforced operator.
- `X <= 1/64`, `|eta| <= 0.5`, `tau in [0.5/64, 0.5]`, h = 0.005.
- Source coordinates: `tau=q(1-eta^2)`, `z_source=q^(1/2-h) eta`,
  `X=r_source^2/(2q)`. Physical coordinates and velocity are multiplied by sqrt(nu),
  pressure by nu.
- No global or per-time energy normalization. No velocity extension by zero.
- This is an autonomous local Taylor method, not the source's global correction
  scheme and not an infinite-series convergence or blow-up theorem.

## Two different frozen axis-data experiments

**ST073-F** uses the smooth ST068 axis traces unchanged: swirl factor 1,
axial profile `4 eta + 0.02`, axis pressure `-1 + eta^2/2`. Its full residual
is small, but the computed radial pressure force points outward on the tested core.
It is retained as a numerical-method control, not the preferred structural example.

**ST073-V** was separately registered after that failure, changes the axis swirl
factor from 1 to 4, and is compared against a newly generated leading-only field
with the **same V axis traces**. This is not a fixed-amplitude improvement or a
repair of the sharp ST072-N field. The fresh V sample sets differ from F's sets.

Both use radial order 8, selected using deterministic calibration and confirmed
at order 10. Five local direction fractions pass on V's independent samples;
they do not imply a compatible interface or global geometry.

## What still fails

At the midplane interface the old leading-background shear diagnostic v is only
about 0.0093–0.0099 for V, far below the old wave-cone prerequisite 2. This is not
a necessary condition for every NS solution, and the old source-cone formula
cannot be reused unmodified for a full corrected background. It nevertheless
shows that the old wave interface has **not** been preserved. Pressure/radial
jets and all interface moments must be recomputed and matched.

No heat exterior, five-moment restoration for these new traces, realizable wave
field, global axial localization, finite total energy, old fixed-force validation,
material winding test, or dynamically produced time-scale recursion is claimed.
No new MATLAB animation is made by cutting off this incomplete local field.
